       This is the core interactive component. Uses TanStack Table with shadcn Table primitives.

       Props: `{ holdings: HoldingRow[] }` where HoldingRow is a serializable plain object with:
       ```typescript
       interface HoldingRow {
         cusip: string
         ticker: string | null
         nameOfIssuer: string
         value: number
         shares: number
         weight: number
         changeType: PositionChangeType
         valueDelta: number
         sharesDelta: number
         weightDelta: number
         convictionLevel: 'high' | 'medium' | 'low'
       }
       ```

       Columns:
       - **Name**: Shows ticker (bold) + issuer name. If no ticker, just issuer name. Links to `/positions/{cusip}?quarter={quarter}` (read quarter from URL via nuqs or just use a prop).
       - **Change**: ChangeBadge component
       - **Value**: formatCurrency(value). Show delta as small text below: "+$X" or "-$X" colored green/red.
       - **Shares**: formatShares(shares). Show delta below.
       - **Weight**: WeightBar component + percentage text. Show weight delta below.
       - **Conviction**: Badge with conviction level (high=green filled, medium=yellow, low=gray/none).

       Features:
       - Sortable columns: Click header to sort. Default sort by weight descending. Use TanStack Table's `getSortedRowModel()`.
       - Show sort direction indicator (arrow up/down) in column headers using lucide-react icons (ArrowUpDown, ArrowUp, ArrowDown).
       - Use shadcn Table, TableHeader, TableBody, TableRow, TableCell, TableHead for rendering.
       - If holdings is empty, show "No holdings data for this quarter" message.
