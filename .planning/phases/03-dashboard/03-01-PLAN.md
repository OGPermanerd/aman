       Replace the default singleton section with:

       const defaultConnection = globalForDb.__hedgelens_db ?? getDb()

    **Part A: Utility modules**

    1. Create `src/lib/slugs.ts` -- bidirectional strategy group slug mapping:
       ```typescript
       const GROUPS = ['Tiger Cubs', 'Activist', 'Macro', 'Quant', 'Multi-Strategy'] as const
       type StrategyGroup = typeof GROUPS[number]

       const SLUG_MAP: Record<string, StrategyGroup> = {
         'tiger-cubs': 'Tiger Cubs',
         'activist': 'Activist',
         'macro': 'Macro',
         'quant': 'Quant',
         'multi-strategy': 'Multi-Strategy',
       }

       const NAME_TO_SLUG: Record<StrategyGroup, string> = Object.fromEntries(
         Object.entries(SLUG_MAP).map(([slug, name]) => [name, slug])
       ) as Record<StrategyGroup, string>

       export function slugToGroup(slug: string): StrategyGroup | undefined
       export function groupToSlug(group: string): string | undefined
       export function getAllGroups(): StrategyGroup[]
       export function getAllSlugs(): string[]
       ```

    2. Create `src/lib/formatters.ts` -- centralized formatting:
       ```typescript
       // formatCurrency(1234567890) -> "$1.23B"
       // formatCurrency(1234567) -> "$1.23M"
       // formatCurrency(1234) -> "$1,234"
       export function formatCurrency(value: number): string

       // formatPercent(0.1234) -> "12.34%"
       // formatPercent(0.1234, 1) -> "12.3%"
       export function formatPercent(value: number, decimals?: number): string

       // formatNumber(1234567) -> "1,234,567"
       export function formatNumber(value: number): string

       // formatShares(1234567) -> "1.23M"
       export function formatShares(value: number): string

       // formatQuarterLabel("2025Q4") -> "Q4 2025"
       export function formatQuarterLabel(quarter: string): string

       // formatQuarterDate("2025Q4") -> "December 31, 2025"
       // Maps Q1->March 31, Q2->June 30, Q3->September 30, Q4->December 31
       export function formatQuarterDate(quarter: string): string
       ```
       Use `Intl.NumberFormat` for currency/number formatting. Compact notation for large values.

    3. Create `src/lib/data.ts` -- server-only data access layer:
       ```typescript
       import 'server-only'
       import { db } from '@/db/connection'
       import { funds, holdings, securities } from '@/db/schema'
       import { eq, and, desc } from 'drizzle-orm'
       import { computePortfolioWeights } from '@/analytics/portfolio-weights'
       import { computeQoQDiff } from '@/analytics/qoq-diff'
       import { computeGroupConsensus } from '@/analytics/group-consensus'
       import { computeConvictionScores } from '@/analytics/conviction'
       import { getAvailableQuarters, previousQuarter } from '@/analytics/quarter-utils'
       ```

       Functions to implement:

       `getGlobalQuarters()`: Returns DISTINCT reportQuarter from all holdings, ordered descending. This is for the quarter picker in the root layout.

       `getGroupOverview(quarter: string)`: For DASH-01 landing page. For each strategy group:
       - Fund count (active funds in group)
       - Funds with data count (funds that have holdings for this quarter)
       - Aggregate portfolio value (SUM of all holdings.value for group funds in quarter, equity only putCall='')
       - Top 5 consensus holdings (from computeGroupConsensus, sliced to 5)
       Return array of `{ name, slug, fundCount, fundsWithData, aggregateValue, topHoldings }`.
       Note: For aggregate value, use a single SQL query per group (SELECT SUM(value) FROM holdings WHERE fundCik IN (...) AND reportQuarter=? AND putCall='') rather than calling computePortfolioWeights per fund.

       `getGroupDetail(strategyGroup: string, quarter: string)`: For DASH-02. Returns:
       - Group info (name, slug)
       - List of funds with: cik, name, hasData (boolean), portfolioValue (sum), holdingCount, qoqSummary (from computeQoQDiff summary)
       Use previousQuarter() for QoQ. Handle funds with no data gracefully (hasData=false, zero values).

       `getFundDetail(cik: string, quarter: string)`: For DASH-03. Returns:
       - Fund info (name, cik, strategyGroup)
       - Holdings with weights, diffs, and conviction merged into a single array per position
       - QoQ summary counts
       Merge computePortfolioWeights, computeQoQDiff.diffs, and computeConvictionScores by CUSIP into unified objects.

       `getPositionDetail(cusip: string, quarter: string)`: For DASH-04. Returns:
       - Security info (cusip, ticker, name, sector from securities table)
       - List of all tracked funds holding this CUSIP in the quarter, with: fundName, fundCik, strategyGroup, value, shares, weight (within that fund), changeType (from QoQ diff)
       - Total fund count holding this position
       Query holdings table for the CUSIP across all funds, join with funds table for names.

       `getSectorBreakdown(fundCik: string, quarter: string)`: For DASH-05. Returns:
       - Array of { sector, value, weight } sorted by weight descending
       Query holdings joined with securities for sector, aggregate by sector, compute weights.

       `getGroupSectorBreakdown(strategyGroup: string, quarter: string)`: For DASH-05 group-level. Same as above but across all funds in a strategy group.
